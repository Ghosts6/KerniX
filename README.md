# void-kernel

A lightweight, experimental kernel written in C and Assembly to practice bare-metal systems programming, virtual memory, and process scheduling.

## Features
- **CPU Scheduler:** Preemptive process/thread scheduling and context switching.
- **MMU & Virtual Memory:** Page tables, physical frame allocation, and paging.
- **Interrupts:** Custom IDT (Interrupt Descriptor Table) and timer tick handling.

## Tech Stack
- **Languages:** C, x86 Assembly
- **Target:** x86 / x86_64
- **Toolchain:** GCC, NASM, GNU Make, QEMU
